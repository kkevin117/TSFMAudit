# Data Directory

Datasets are not included in this anonymous code release.

Expected local layout:

```text
/path/to/data/
├── GIFT-Eval/
└── GIFT-Eval-Pretrain/
```

Configure paths with environment variables:

```bash
export DATA_ROOT=/path/to/data
export GIFTEVAL_ROOT=$DATA_ROOT/GIFT-Eval
export GIFTEVAL_PRETRAIN_ROOT=$DATA_ROOT/GIFT-Eval-Pretrain
```
